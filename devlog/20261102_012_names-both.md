# 012 이름 병기 — 원래 이름 · 한글 · 병기

**날짜** 2026-11-02 · 사용자: "한글 이름과 로마자 이름을 병기하는 기능도"

## 바꾼 것

011 의 켜고 끄는 칸(`koNames`)을 **세 갈래 고르기**로 바꿨다 — Original · 한글 · Both. 설정의 Theme·Font 와 같은
단추 묶음(`.seg`)이다. 값은 `confoinfo_cfg.names`(`orig`·`ko`·`both`).

- **Both 는 `최경식 (Kyungsik Choi)`** — 한글을 앞에, 원래 이름을 괄호에 조금 작고 흐리게. 한글을 고른 사람이 읽는
  것은 한글이고 원래 이름은 대조용이라서다. 좌장 칸은 `Conveners: 최경식 (Kyungsik Choi), 산신 (Xin Shan)` 이 된다
- 한글에서 이름을 누르면 원래 이름과 오가는 것(011)은 그대로다. Both 에서는 둘 다 보이니 누르는 것을 걸지 않았다
- **0.11.0 에서 켜 둔 사람은 한글로 이어진다** — `names` 가 없고 `koNames` 가 참이면 `ko` 로 본다. 옛 값을 지우지는
  않는다(새 값이 앞선다)
- 바꿔 둔 이름에 모양을 적어 두고(`data-mode`), 모양이 바뀐 것만 원래 글로 되돌렸다가 다시 바꾼다. 같은 모양이면
  `refresh` 마다 다시 손대지 않는다

## 버린 것

- **`Kyungsik Choi (최경식)` — 원래 이름을 앞에** 두는 순서. 한국어 사용자가 고르는 칸이라 한글을 앞에 뒀다.
  바꾸려면 `app.js` 의 `swapNames` 한 자리다
- 두 줄로 쌓기(한글 위, 원래 이름 아래) — 저자를 쉼표로 이어 쓰는 칸에서는 줄이 엉킨다

## 확인

시험 37개 · 개발 서버: 설정에서 옛 `koNames` 가 "한글" 로 칠해진다 · Both 를 누르면 `names: "both"` · 세션 1A 의
좌장·저자가 Both → 한글 → Original → Both 로 바뀌고 되돌아온다
