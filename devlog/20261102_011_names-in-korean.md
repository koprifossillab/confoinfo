# 011 사람 이름을 한글로 보이기

**날짜** 2026-11-02 · 사용자: "설정에 사람 이름 한글로 보이기 만들어서, 해당 설정을 켜면 사람 이름 다 한글로
보이도록" · 범위를 물으니 "모든 이름"(외국인도), 학회는 "ICAMG만"

## 자료 — `enrich/icamg2026.names.json`

006 의 번역처럼 **이 세션의 Claude 가 미리 적어 넣었다.** 자료에 적힌 이름 그대로가 열쇠다
(`{ko: {"Kyungsik Choi": "최경식"}}`). ICAMG 이름 465개 중 457개. 남은 여덟은 이름 여럿이 붙은 칸
("Dr. Ken Ikehara (Convener: Shouye Yang)")이나 사람이 아닌 것("IODP Expedition 503 Scientists")이다 —
붙은 칸은 화면이 그 안의 이름을 하나씩 찾아 바꾸므로 따로 적지 않는다.

적는 규칙:

| 누구 | 어떻게 | 예 |
|---|---|---|
| 한국인 | 성을 앞에, 붙여 쓴다 | Kyungsik Choi → 최경식 |
| 중국·대만인 | 외래어 표기법, 성을 앞에 붙여 쓴다 | Xin Shan → 산신, Chuan-Chou Shen → 선촨저우 |
| 일본인 | 성을 앞에, 띄어 쓴다 | Ken Ikehara → 이케하라 겐 |
| 그 밖 | 적힌 순서대로 | Michael J McPhaden → 마이클 J 맥페이든 |
| 이니셜 | 영문은 그대로 | B.K. Khim → B.K. 김 |

**로마자만 보고 골랐다.** 한국 이름의 한자(경식/경직)나 중국 이름의 성 자리("Sheng Jie"·"Jie Sheng" 이
같은 사람인지)는 짐작이다. 설정 문구에 "a few may be off" 를 적었고, 이름을 누르면 원래 이름이 나온다.

## 화면

- 설정 Translate 아래 **Names in Korean**(`confoinfo_cfg.koNames`, 기본 꺼짐). 한글 표기가 있는 학회를 적는다
- `names.json` 하나로 굽는다 — 학회를 가로지른다(내 계획·전체 검색이 여러 학회를 한 화면에 그린다).
  이름이 같으면 같은 사람으로 본다
- `app.js` 가 이름이 놓인 칸(`.author`·`.detail-authors`·`.detail-corr`·`.sconv`·`.session-conveners`·
  `.scholar-name`, JS 가 그린 것은 `.pn`)의 글에서 아는 이름을 찾아 `<span class="ko-name" title=원래 이름>`
  으로 바꾼다. 칸 전체를 사전에서 찾지 않고 글 속에서 찾는 것은 "A, B, C" 로 이어 쓴 칸, 줄여 쓴 칸("…"),
  좌장이 붙은 칸이 있어서다. 긴 이름부터 맞추고 글자가 이어지는 자리에서는 안 맞춘다("Bo Li" 가 "Bo Lin" 을
  안 먹게). 끄면 원래 글로 되돌린다
- 이름을 누르면 원래 이름과 오간다 — 휴대폰은 title 이 안 뜬다. 링크·자동완성 안에서는 안 바꾼다
- Scholar 링크·캘린더·검색어로 넘기는 이름은 원래 이름 그대로다

## 검색

설정과 무관하게 한글 표기로도 찾는다 — "이케하라" 가 Ken·Minoru Ikehara 에 걸린다. 007 의 `kname.js` 는
한국 이름만 받으므로 외국 이름은 이 자료로 찾는다. 찾을 글에 넣을 때도 붙은 칸 안의 이름을 하나씩 바꾼다
(처음에 칸 전체를 사전에서 찾았더니 "Prof. Kyung Eun Lee (Convener: Minoru Ikehara)" 가 빠졌다).

## 버린 것

- **브라우저에서 로마자를 한글로 규칙 변환** — 외국 이름은 규칙으로 안 되고, 한국 이름도 표기가 갈려
  (Kyung/Kyeong/Gyeong) 되돌리면 틀린다. 007 은 한글 → 로마자 뼈대로 "찾기"만 했다
- STRATI 2026(2,059명) · 추계연합의 로마자 이름(399명) — 사용자가 ICAMG 만 골랐다
