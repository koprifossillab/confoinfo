# 007 검색 자동완성 · 한글로 저자 찾기

**날짜** 2026-10-08 · 사용자: "검색창에 자동완성하고 저자 이름을 한국어로 검색했을 때도 뜨도록"

## 한글 이름 → 로마자 저자 (`static/conference/kname.js`)

한국 이름의 로마자 표기는 사람마다 다르다 — 최: Choi·Choe, 경: Kyung·Kyeong·Gyeong,
정: Jung·Jeong·Chung, 이: Lee·Yi·Rhee. 표기를 하나로 정해 옮기면 거의 안 맞는다. 그래서:

- **성은 표로 댄다.** 흔한 성 백여 개와 복성 여섯(남궁·황보·제갈·선우·독고·사공)의 흔한 표기.
  규칙으로 안 나오는 것이 많아서다(이 → Rhee, 박 → Park, 안 → Ahn, 손 → Sohn)
- **이름은 양쪽을 "뼈대"로 접어 비교한다.** 한글은 국어의 로마자 표기법으로 옮기고(음절마다,
  소리 바뀜은 안 봄), 저자 이름과 함께 표기가 갈리는 자리를 접는다 — yeo/yu → yo, eo·ou → o,
  oo → u, ee → i, eu → u, ae·oe → e, sh → s, ch·j → c, k → g, t → d, p → b, l → r, 끝으로 u → o,
  겹친 글자 하나로. Kyungsik · Kyung-Sik · Gyeongsik 이 모두 `gyongsig` 가 된다
- 저자 이름은 "이름 성"(Kyungsik Choi)과 "성 이름"(Choi Kyungsik) 둘로 본다. 한 글자만 치면 성으로,
  두 글자 이상은 성+이름과 이름만(경식) 둘로 본다

**느슨하게 접는다** — 구·고, 유·요 가 같은 뼈대가 된다. 이름 검색은 놓치는 것보다 더 걸리는 편이
낫다(결과를 사람이 본다). ICAMG 실제 저자 열아홉 쌍으로 맞혀 봤다(중국 이름 Xin Shan 이 "신" 에
안 걸리는 것 포함).

## 자동완성

`search.json` 에 저자 이름 목록(`n`)과 세션 제목(`st`)을 더해 브라우저가 목록을 만든다. 저자(발표 수
순 다섯) · 세션(셋) · 발표 제목(셋). 저자·세션을 고르면 그것으로 찾고, 발표를 고르면 그 발표로
간다. 방향키·엔터·Esc. 한글은 조합 중에도 `input` 이 와서 그대로 따라간다.
