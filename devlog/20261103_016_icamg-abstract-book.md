## 길 — 사이트판 위에 얹는다

10-08 사이트판(HTML)을 다시 받아 바꾸지 않고, PDF 에서 뽑은 것을 그 위에 얹었다.

- `abstract_book.py` — PDF → `output/abstract_book.json`(커밋한다). PDF 없이도 `to_confoinfo.py` 가 다시 돈다
- `merge_book.py` — `to_confoinfo.py` 가 자료를 다 만든 뒤 부른다. 겹치는 것은 PDF(나중 판)를 따른다

**key 는 바꾸지 않았다.** 북마크가 key 에 붙는다. 구두 key 가 "세션-시각"(1A-1300)이라 시각이 옮겨진 발표는 key 와
시각이 어긋난다 — 그래도 둔다. 발표는 **제목으로** 짝지었다(유사도 0.8 이상, 높은 쌍부터 하나씩). 같은 세션 안의 순서가
바뀐 것이 많아 "세션-시각" 으로 짝지으면 다른 발표에 북마크가 옮겨 간다.

## 초록

182 / 183편에 본문을 넣었다(짝 없는 하나 = 위의 4A-1550). 기조강연 셋은 초록 행이 없어 발표 key 로 만들었다.
**공동 세션(World Ocean Forum) 초록 셋은 넣지 않았다** — 연사 셋이 시간 없이 한 행이라 붙일 발표가 없다.

- **글꼴 크기는 쪽마다 다르다**(저자 6.5pt 또는 10pt, 위첨자가 ¹²³ 글자이기도, 들여쓰기 76–93pt) — 자리로 가른다:
  제목(Arial Bold 12) 아래, "*Presenting Author" 위가 머리. 머리의 첫 크기 줄이 저자, 작은 줄이 소속. 본문은 그 다음
  본문 크기 줄부터, 들여 쓴 줄마다 새 문단. 그림 설명(이탤릭)·참고문헌(7.9pt)은 뺀다
- **전자우편은 뺐다** — 사람의 연락처다
- 한 줄에 소속이 둘("3Korea Environment Institute, 4Research Institute …")이면 번호 앞에서 가른다
- 부제가 초록에만 붙은 제목(P73)은 앞머리가 같으면 짝짓는다

**저자 이름은 사이트판(프로그램 표기)을 둔다.** PDF 의 저자 줄은 원고 그대로라 꼴이 제각각이다(쉼표·세미콜론 섞임,
"T. 1*Khim, B.K. Irino" 처럼 엉킨 줄). 이름 한글 표기(011)의 열쇠도 프로그램 표기다. 소속 번호는 **성이 맞는 저자에게만**
붙인다. 포스터는 프로그램에 발표자만 있어 공저자를 더하지 않았다.

구두 저자 목록은 PDF 프로그램 쪽의 것으로 바꿨다(표기가 사이트판과 같은 꼴) — 새로 나온 이름 여섯을
`enrich/icamg2026.names.json` 에 더했다(Hyun Ju Ha 하현주 등). 제목이 바뀐 12건은 한국어 제목을 새로 넣었다(`i18n_todo`).
