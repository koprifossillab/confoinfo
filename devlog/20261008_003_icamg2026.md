# 003 ICAMG 2026 을 넣는다 — 학회 사이트의 HTML 에서

**날짜** 2026-10-08 · 사용자 요청 "https://icamg.org/program 이 페이지 데이터 이식"

## 원본

`icamg.org/program` 한 페이지에 표가 셋 있다 — 한눈에 보는 표(`#programmeGridPanel`),
구두 발표 시간표(`#detailedProgrammeGridPanel`, 발표마다 저자·제목), 포스터 목록
(`#posterPresentationsPanel`, 번호·제목·발표자·소속). 세션 소개는 `proposed-session`.
둘 다 `sources/icamg2026/raw/` 에 커밋했다(`fetch.sh` 로 다시 받는다). 학회 사이트는
고쳐지고 사라지므로 어느 판에서 뽑았는지를 git 이 갖고 있어야 한다.

결과: 룸 5 · 세션 36(구두 18 · 포스터 18) · 발표 196(구두 108 · 포스터 75 · 기조 3 ·
행사 7 · 점심 3) · 초록 184(저자만). 원본의 `talk-cell` 108 · `poster-no-cell` 75 와 같다.

## 판단

**구두 세션은 프로그램의 표기(1A … 7B)를 쓴다.** 그것은 시간 칸 번호이고, 주제 세션
(1-1 …)과 다르다 — 1B·2B 는 같은 주제(5-2 남극)의 I·II 다. 참가자가 보는 것이 1A 이므로
그것을 세션으로 두고, 소개 글만 주제 세션에서 가져온다. **포스터는 주제 번호로 묶여 있어**
`P1-1` 처럼 P 를 붙였다(구두 `1A` 와 겹치지 않게).

**시간표 세션 → 주제 세션 짝짓기는 좌장으로 먼저 한다.** 제목으로만 했더니 4C("Carbon
cycling and subsurface CO2 storage")가 엉뚱한 극지 세션에 붙었다 — 시간표의 제목이 줄여
쓰인 곳이 있다. 좌장으로도 동점이 났다(4C 의 두 사람이 5-4 와 6-2 에 다 있다). 그래서
**명단이 똑같은 것 → 겹침 수 → 제목 유사도** 순이다. 18개 모두 맞는 것을 눈으로 확인했다.

**자료 형식에 셋을 더했다.**
- 세션 `conveners`·`description` — 국제 학회는 거의 다 좌장과 세션 소개가 있다. STRATI 2026 에는
  없어서 빠져 있던 것이다
- 발표 `code` — 포스터를 보드 번호로 찾는다. 제목에 섞으면 검색·정렬이 더러워진다

**포스터는 한 장씩 발표로 둔다** — 월요일 16:40~18:00, Seaside Hallway. 북마크와 내 계획에
들어가야 해서다. 내 계획에서 여러 장이 같은 시간이면 겹침 격자가 그린다.

**커피 휴식은 버렸다** — 빈 시간에서 끌어낸 휴식과 같은 것이다. 점심은 `kind: break` 로
Event Hall 에 둔다(점심 장소가 적혀 있다). 등록 데스크는 룸 없는 행사.

**기조 강연의 연사와 제목은 한눈에 보는 표에서 가른다.** 시간표 쪽은 "Keynote: Prof. X 제목"
이 붙어 있어 어디서 끊을지 모르고, 한눈에 보는 표는 "– 제목 –" 으로 감싸 있다.

**World Ocean Forum 공동 세션**은 연사별 시각이 없어 한 행으로 두고 연사 목록을 초록 칸에
적었다(TBD 한 명 포함 — 원본 그대로).

## 발표 pk 를 자료에서 계산한다 — 북마크가 밀렸다

ICAMG 를 넣고 사이트를 구웠더니 **STRATI 2026 의 발표 pk 가 전부 바뀌었다.** 002 에서 정적
사이트로 옮기며 빌드마다 빈 DB 에 새로 읽게 됐는데, pk 는 DB 의 일련번호라 **읽는 순서**로
정해진다 — `icamg2026.json` 이 알파벳상 앞이라 먼저 196개를 가져갔다. 001 의 "key 로 맞춰
pk 를 지킨다" 는 DB 가 계속 살아 있을 때의 이야기였다. 그 전제가 002 에서 깨진 것을 그때
못 봤다.

`loader.stable_id(slug, key)` — sha1 의 앞 52비트(JS `Number` 로 정확)를 pk 로 쓴다.
초록도 같다(`abstract/<key>`). 시험이 학회를 앞에 하나 끼우고 같은 pk 가 나오는지 본다.

**v0.2.0 에서 STRATI 2026 에 붙인 북마크는 이번에 한 번 끊긴다** — pk 가 1~457 에서 해시로
바뀌었다. v0.2.0 이 떠 있던 것은 한 시간 남짓이고 STRATI 는 지난 학회라 옮기는 길은 두지 않았다.

## 받은 날 없던 것

초록 본문(E-abstract Book "Coming Soon") · 층 · 답사(10-30~11-01, 11-05~07) 시각. 본문이
올라오면 `fetch.sh` 로 다시 받고 파서에 갈래를 하나 더한다. **발표 `key` 를 행 순서(`t1` …)로 매기면
원본에 행이 끼면 북마크가 밀린다** — 처음에 그렇게 짰다가 바꿨다. 구두는 `세션-시작시각`
(`1A-1300`), 기조·행사·점심은 `날짜-시작시각-종류`, 포스터는 보드 번호(`p12`). 발표 시각이
바뀌면 그 발표의 북마크는 끊긴다 — 제목으로 key 를 만들면 오타 하나 고친 것에 끊긴다.
어느 쪽이든 다시 뽑을 때는 사라진 key 가 없는지 diff 로 본다.
