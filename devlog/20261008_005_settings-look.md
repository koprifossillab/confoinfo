## GSM 에서 가져온 것

GSM(`web/viewer/`)은 모양 설정을 전부 **`<html>` 의 속성 하나 + CSS 토큰 + localStorage** 로
한다(`data-theme`·`data-font`, `LOOKS` 표 · `readLook` 이 목록에 없는 값을 기본값으로 거른다).
판 이력은 `CHANGELOG.md` 를 서버가 읽어(`patchnotes.py`) 설정 시트의 탭에 낸다. 같은 틀로 했다.

다른 점:
- **테마에 Auto 를 둔다.** GSM 은 먹갈색·한지 둘이고 기기 설정을 안 본다. confoinfo 는 폰으로
  보는 앱이라 기기의 다크 모드를 따르는 것이 기본이다(`prefers-color-scheme`, 바뀌면 바로 따라감)
- **그리기 전에 단다.** GSM 은 스플래시가 깜빡임을 가린다. 여기는 스플래시가 없어 `<head>` 의
  한 줄 스크립트가 CSS 보다 먼저 `data-theme`·`data-font` 를 단다
- **글자 크기는 안 했다.** CSS 가 전부 px 라 한 토큰으로 안 바뀐다. 요청에도 없었다
- 판 이력은 CHANGELOG 의 **표**를 읽는다(GSM 은 `## v…` 머리). 구운 사이트라 빌드 때 그려진다.
  devlog 링크는 사이트에 없어 글자만 남긴다. 한국어로만 적는다는 것을 영어로 한 줄

## 색을 토큰으로

다크를 얹으려니 CSS 에 고정 색이 스무 군데 남짓 있었다(strati2026 에서 온 것). 전부 `:root` 의
토큰으로 옮기고 `:root[data-theme="dark"]` 가 갈아 끼운다. **`--navy` 를 둘로 갈랐다** —
칠하는 색(머리글·배지·학회 color)은 `--navy`, 글자색은 `--link`. 다크에서 칠하는 색은 그대로
두고 글자색만 밝힌다. 남색 글자는 어두운 바탕에서 안 읽힌다.

## 기본 학회 · 학회 목록으로

설정 맨 위. 고르면 첫 화면(`/`)이 그 학회로 `location.replace` 한다. 그러면 목록으로 갈 길이
막히므로 **목록으로 가는 링크는 전부 `?all` 을 단다**(머리글 `‹ All` · 브랜드 · 탭바). 학회 화면
머리글 왼쪽에 `‹ All`, 오른쪽에 설정(⚙️) — 예전에는 오른쪽 🗂️ 가 목록이었고 학회 안에서
설정으로 갈 길이 없었다. 목록에서는 기본 학회 카드에 DEFAULT 를 단다.

## 새어 나온 주석

Django 의 `{# #}` 는 **한 줄짜리다.** base.html 에 여러 줄로 단 주석이 모든 화면 맨 위에 글로
나왔다(헤드리스 화면에서 봤다). 여러 줄 주석은 `{% comment %}` 로 바꿨고, **굽기가 그려진
HTML 에 `{#`·`{%`·`{{` 가 남았으면 실패로 끝낸다.** 일부러 새는 주석을 넣어 잡히는 것을 봤다.
plan.html·settings.html 에도 여러 줄 `{# #}` 가 있었지만 블록 밖이라 Django 가 버려 화면에는
안 나왔다 — 같이 고쳤다.
