## 왜

strati2026 은 Tailscale 사설망으로 폰에서 열었다 — m710q 의 `:8010`, 폰에 Tailscale 앱을
깔고 같은 tailnet 에 들어간 사람만(strati2026 `devlog/004`, `CLAUDE.md`). 001 에서 따른
ForGIA 틀(사내망 + nginx `/confoinfo/`)은 그보다 좁다 — 학회장에서 폰으로 못 연다.

사용자가 GitHub Pages 를 골랐다. **1단계의 confoinfo 에는 서버가 할 일이 없었다** —
북마크·메모는 원래 브라우저에 있고, 학회 자료는 저장소의 파일이다. 서버가 하던 것은
HTML 그리기·검색·`api/talks`·`.ics` 뿐이라 전부 굽거나 브라우저로 옮길 수 있다.
그 대가로 **기기 간 동기화(strati2026 028~039)는 안 옮긴다** — 사용자 확인. 초록 본문도
공개 페이지에 넣는다 — 사용자 확인(저장소가 이미 public 이기도 하다).

## 한 것

- `build_site` — Django 시험 클라이언트로 경로마다 GET 해서 파일로 적는다. 화면 코드는
  개발 서버와 하나다. 끝에 구운 HTML 의 href·src 를 전부 따라가 **없는 파일이 있으면 실패**
- `tools/build_site.sh` — 임시 DB · import · collectstatic(해시 이름) · build_site. 개발 DB 를 안 건드린다
- `.github/workflows/pages.yml` — 시험 → 굽기 → Pages. PR 은 굽기(링크 검사)까지
- Docker·nginx·`/srv`·`deploy.sh`·`smoke.sh`·whitenoise·gunicorn 을 걷었다 (001 의 배포 틀 전부)

## 서버가 하던 일을 어디로

| strati2026 / 001 | 지금 |
|---|---|
| `?day=` 로 날짜 | 경로 `/<slug>/day/<날짜>/`. 뿌리 `/<slug>/` 는 첫째 날 |
| 서버가 "개최지의 오늘" 을 골라 그날을 그린다 | 뿌리에서 JS 가 오늘이 일정에 있으면 `location.replace` |
| 첫 화면의 진행 중·다가올·지난 | 카드에 `data-start`·`data-end`·`data-tz` — JS 가 가른다 |
| 검색 `?q=` → DB `icontains` | `search.json`(STRATI 2026 390 KB)을 받아 브라우저에서. **악센트를 지운다**(`fold`) — `montanez` 가 `Montañez` 에 걸린다. 낱말이 모두 들어 있어야 걸린다 |
| `/api/talks/?ids=` | `talks.json` 통째로(180 KB) — 내 계획이 북마크만 고른다. 적힌 휴식(`kind: break`)도 휴식 목록에 넣었다 |
| `/calendar.ics?ids=` | 발표 하나는 구운 `talk.ics`, 여러 발표는 JS(`buildIcs`)가 만든다. 개최지 시각 → UTC 는 `Intl` 로 오프셋을 구해 두 번 맞춘다(서머타임 경계) |
| `/healthz` | 없다 — 지켜볼 서버가 없다 |
| 404 | `404.html` (Pages 가 쓴다) |

**뷰가 요청과 무관해야 한다**는 것이 이번의 규칙이다. `request.GET`·`timezone.now()` 를 뷰에
들이면 개발 서버에서는 맞고 구운 사이트에서만 굽는 순간의 값으로 굳는다. 시험이 하나
지킨다(`test_program_root_is_first_day_and_independent_of_now`).

`talk.ics` 의 `DTSTAMP` 는 발표 시작 시각으로 뒀다 — 지금 시각으로 두면 구울 때마다 파일
1,000여 개가 바뀐다.
