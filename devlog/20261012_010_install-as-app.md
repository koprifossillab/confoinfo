# 010 앱으로 설치 — manifest · 서비스 워커 · 아이콘

**날짜** 2026-10-12 · 사용자 요청 "이것도 https://github.com/wetherilli/konzentrat 처럼 앱으로 설치해서 볼 수 있게 해줘"

## 한 것

konzentrat 의 틀을 따랐다 — manifest 하나, 네트워크 먼저인 서비스 워커, 크기별 아이콘. 안드로이드 크롬은 "앱 설치", iOS 사파리는 공유 → "홈 화면에 추가"로 깔린다.

| 파일 | 무엇 |
|---|---|
| `/confoinfo/manifest.webmanifest` | `views.manifest`. 범위·시작이 사이트 뿌리(`/confoinfo/`) — 학회 하나가 아니라 Confoinfo 전체가 앱이다 |
| `/confoinfo/sw.js` | `views.service_worker` + `templates/conference/sw.js`. 범위의 뿌리에 있어야 해서 static/ 이 아니라 뷰로 굽는다 |
| `static/conference/icons/` | 사용자가 만든 아이콘(배·바다·별) 그대로. 원본 SVG 와 가로 로고는 `docs/brand/` |

## 판단

**네트워크 먼저, 4초 넘으면 캐시.** konzentrat 은 네트워크가 실패할 때만 캐시로 간다. 학회장 와이파이는
끊기기보다 느리다 — 실패를 기다리면 몇십 초 빈 화면이다. 그래서 4초 안에 안 오면 캐시에 있는 것을 내고,
늦게 온 응답은 캐시만 고친다. 캐시에 없으면 끝까지 네트워크를 기다린다.

**미리 받는 것은 껍데기뿐.** 첫 화면·설정·내 계획·`talks.json`·CSS·JS·아이콘. 학회 화면은 연 것이
남는다. 학회 하나를 통째로(발표 상세 500쪽) 미리 받는 것은 약한 와이파이에서 무겁고, 무엇을 받았는지
사용자가 모른다 — TODOs 의 "오프라인" 은 이것으로 반만 했다.

**캐시 이름이 판 번호다** (`confoinfo-0.10.0`). 판을 올리면 새 워커가 옛 캐시를 지운다. CSS·JS 는
이름에 해시가 붙어 따로 신경 쓸 것이 없다.

**아이콘은 받은 것을 그대로 쓴다.** konzentrat 처럼 그림 한 장에서 여백을 넣어 뽑는 도구(Pillow)를 먼저
만들었지만, 받은 아이콘이 크기마다(192·512·마스커블·iOS·파비콘) 이미 다 있고 바탕까지 꽉 찬 그림이라
도구가 여백을 넣으면 오히려 망가진다. 도구는 버렸다.

**manifest 의 색은 기본 남색 하나.** 학회마다 머리글 색이 다르지만 앱은 하나다.

## 함정

- **iOS 는 홈 화면 앱의 저장소가 사파리와 따로다.** 사파리에서 ☆ 한 북마크는 설치한 앱에 안 보인다
  (안드로이드 크롬은 같이 쓴다). 동기화가 없으니 iOS 는 앱을 깐 뒤 거기서 북마크해야 한다
- Playwright 의 `context.set_offline(True)` 는 서비스 워커의 fetch 를 막지 않는다 — 시험할 때는
  미리 보기 서버를 실제로 끈다
